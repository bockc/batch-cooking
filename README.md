# BATCHDAY

Weekend batch cooking for athletes — high-protein lunches, portion-based shopping lists, and detailed cook guides.

## Live site (GitHub Pages)

1. Push this repo to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then save.

Your site will be at `https://<username>.github.io/<repo>/`.

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## What’s included

- **Batch planner** — pick a lunch and portion count (default 5)
- **8 high-protein meals** — poultry, fish, beef, vegetarian
- **Detailed cook guides** — timed steps with checkboxes, equipment, scaled ingredients
- **Shopping list** — scaled to portions, copyable
